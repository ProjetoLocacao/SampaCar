Locacar1 - MVC Flask + SQL (no JSON)
==================================

Este projeto usa SQLite (locacar1.db) via SQLAlchemy.
Senhas são armazenadas com hash (werkzeug).

Como usar:
1. Criar virtualenv e instalar dependências:
   pip install flask flask_sqlalchemy

2. Rodar (no primeiro start, o banco será criado e populado automaticamente):
   python run.py
